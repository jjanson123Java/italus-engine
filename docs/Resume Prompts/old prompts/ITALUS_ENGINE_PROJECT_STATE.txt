ITALUS ENGINE – MASTER PROJECT STATE

PROJECT
Italus Historical Fantasy Generation Engine


--------------------------------------------------
PURPOSE
--------------------------------------------------

The Italus Engine is a structured AI-assisted narrative generation system designed to produce historically grounded fantasy scenes, chapters, and outlines using a carefully constructed canon framework.

The central narrative device is Italus, the world's oldest living tree, which silently witnesses human history across centuries. Italus does not speak; instead, human guardians interpret and carry the story of Italus through successive eras.

The engine uses layered canon documents to constrain AI generation so that produced narrative remains consistent with:

• historical chronology
• guardian succession
• emotional stage evolution
• geographic movement of Italus
• narrative role of each book in the series

The engine is initially being developed for the Italus Historical Fantasy Saga but is designed to later support additional genres through reusable canon templates.


--------------------------------------------------
ENGINE DESIGN PHILOSOPHY
--------------------------------------------------

The Italus Engine separates canon knowledge from generation logic.

Canon documents define the world, timeline, characters, and narrative structure.

Python modules convert canon into compressed prompt packets that guide AI generation.

This architecture prevents LLM drift by ensuring that generation always receives structured canon subsets relevant to the specific request.

This layered prompt system allows the engine to remain both:

• historically grounded
• narratively consistent


--------------------------------------------------
CANON ARCHITECTURE
--------------------------------------------------

The system operates with three canonical layers.


--------------------------------
1. SOURCE CANON
--------------------------------

These files contain the authoritative world structure.

italus_saga_architecture_map.txt  
ITALUS_HISTORICAL_EVENT_BACKBONE.txt  
ITALUS_SCENE_GENERATOR_MATRIX.txt  


Architecture Map

Defines:

• Book numbers and titles  
• Year ranges  
• Primary guardians  
• Guardian continuity  
• Italus emotional stage  
• Historical anchor events  
• Travel route of Italus  
• Narrative function of the book  


Historical Event Backbone

Defines the global historical timeline used by the series.

Each row contains:

Event ID  
Year  
Event Name  
Region  
Book Label  
Guardian  


This document anchors the narrative in real historical transitions.


Scene Generator Matrix

Defines the narrative seeds used for generation.

Each row contains:

Scene ID  
Event ID  
Year  
Book Label  
Guardian  
Location  
Scene Type  
Historical Character  
Scene Seed  


This matrix allows the engine to generate historically grounded narrative scenes.


--------------------------------
2. DERIVED CANON
--------------------------------

These files compress the source canon into structured narrative reference packs.

ITALUS_KNOWLEDGE_PACK_CORE.txt  
ITALUS_KNOWLEDGE_PACK_GENERATION.txt  


Core Canon Pack

Defines global narrative laws such as:

• Italus never speaks  
• Guardians interpret Italus  
• Guardian succession rules  
• Emotional stage evolution  
• Narrative interpretation rules  


Generation Canon Pack

Defines generation guidance including:

• scene archetypes  
• narrative tone guidelines  
• historical interaction rules  
• story progression patterns  


--------------------------------
3. BOOK CANON PACKS
--------------------------------

These are generated automatically.

canon_packs/

ITALUS_KNOWLEDGE_PACK_BOOK_01.txt  
ITALUS_KNOWLEDGE_PACK_BOOK_02.txt  
...  
ITALUS_KNOWLEDGE_PACK_BOOK_11.txt  


Generated by:

canon_bootstrap_book_builder.py


Each book pack contains compressed canon for a single book including:

• Book metadata  
• Active guardians  
• Transition guardians  
• Guardian continuity notes  
• Emotional stage context  
• Travel route of Italus  
• Narrative function of the book  
• Historical anchor events  
• Backbone rows linked to the book  
• Scene matrix rows linked to the book  


--------------------------------------------------
GUARDIAN CONTINUITY MODEL
--------------------------------------------------

Books may contain multiple guardians.

This occurs during historical transitions when one guardian era ends and another begins.

To prevent AI confusion, rows are separated into three categories.


Dominant Guardian Rows

Rows belonging to the primary guardian era of the book.


Transition Rows

Rows where guardian handoff occurs or where guardians overlap.

Example:

Rosa / Theodora Bassi  
Theodora Bassi / Final Guardian  


Carryover Rows

Rows belonging to guardians associated with the book span but not defining the dominant narrative period.


This separation prevents the AI from flattening guardian transitions across an entire book.


--------------------------------------------------
ITALUS EMOTIONAL STAGE MODEL
--------------------------------------------------

The emotional state of Italus evolves across the series.

Example stages:

Stage 1 — Curiosity  
Stage 2 — Awakening  
Stage 3 — Detachment  
Stage 4 — Witness  


Some books include late-stage transitions.

These are captured as:

BOOK STAGE  
LATE BOOK STAGE TREND  


This allows generation to adjust tone during late-book scenes.


--------------------------------------------------
ENGINE MODULES
--------------------------------------------------

The engine is implemented in Python.


canon_bootstrap_book_builder.py

Generates book canon packs by parsing the source canon.

Responsibilities:

• parse architecture map  
• parse backbone rows  
• parse scene matrix rows  
• infer guardian phase labels  
• derive compressed prompting context  
• separate dominant / transition / carryover rows  
• generate book canon packs  



project_runner.py

Main execution entry point for the engine.

Responsibilities:

• load canon packs  
• receive generation requests  
• assemble prompt context  
• execute generation  
• capture generated output  



prompt_builder.py

Constructs the final generation prompt.

Expected prompt structure:

CORE CANON PACK  
GENERATION CANON PACK  
BOOK CANON PACK  
REQUEST PACK  



request_builder.py

Converts user input into structured request packets.

Example request:

Book: 7  
Year: 1662  
Guardian: Agata  
Location: Florence  
Scene Type: historical encounter  



ITALUS_PROJECT_RUNNER_MENU_TONE.py

Command-line interface for the engine.

Functions include:

Generate scene  
Generate chapter  
Generate outline  
Generate historical interaction  


This module calls project_runner.py.
