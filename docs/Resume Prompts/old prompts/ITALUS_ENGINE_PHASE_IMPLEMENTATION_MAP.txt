ITALUS ENGINE – PHASE IMPLEMENTATION MAP

This file tells the AI which files must be modified in each phase.

--------------------------------------------------

PHASE 2 – PROTOTYPE ENGINE

OBJECTIVE
Create the first working Italus generation engine.

FILES
project_runner.py
prompt_builder.py
request_builder.py
ITALUS_PROJECT_RUNNER_MENU_TONE.py

ORDER

1
Load canon packs in project_runner.py

2
Inject canon into prompt_builder.py

3
Build request_builder.py

4
Wire CLI menu to runner

5
Implement output saving

DONE WHEN

User can generate scenes from CLI and results are saved.
